# Neon Deals

Адаптивное React-приложение для поиска скидок на компьютерные игры и анализа текущих предложений из [CheapShark API](https://apidocs.cheapshark.com/).

Проект выполнен на JavaScript и JSX. Он не требует API-ключа или файла с переменными окружения.

Репозиторий: [ArishkaWolf/CPD_Neon-Deals](https://github.com/ArishkaWolf/CPD_Neon-Deals)

## Возможности

- Поиск предложений по названию игры.
- Фильтрация по магазину, диапазону цены и рейтингу Metacritic.
- Быстрые фильтры: только скидки, AAA, Steam activation, высокий рейтинг и скидка от 50%.
- Сортировка по цене, рейтингу, дате выхода, размеру скидки и рейтингу сделки.
- Выбор направления сортировки.
- Пагинация с текущей и общей численностью страниц из заголовка CheapShark.
- Карточки с fallback-обложкой, платформой PC, магазином, ценами, скидкой, рейтингами и датой выхода.
- Страница подробной информации о сделке и альтернативных предложений.
- Переход в магазин через CheapShark redirect.
- Отдельная страница аналитики по 60 актуальным предложениям.
- Графики распределения скидок, магазинов, цены и рейтинга сделки.
- Светлая и тёмная темы с сохранением выбора в `localStorage`.
- Адаптивная раскладка для десктопа, планшета и телефона.
- Состояния загрузки, ошибки и пустой выдачи.
- Синхронизация применённых фильтров и сортировки с URL.
- Валидация диапазона цен и рейтинга до отправки формы.
- Фильтр магазина на странице аналитики.

## Установка и запуск

Перейдите в папку проекта и установите зависимости:

```bash
cd lab1-cheapshark-games
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

Vite выведет локальный адрес приложения, обычно `http://localhost:5173/`.

```bash
npm run dev
```

## Маршруты

| Маршрут | Назначение |
| --- | --- |
| `/#/` | Поиск, фильтрация и просмотр предложений |
| `/#/analytics` | Аналитика текущих скидок |
| `/#/deal/:dealId` | Подробная информация о выбранной сделке |

Приложение использует `HashRouter`, поэтому маршруты работают на статическом хостинге без серверных правил перенаправления.

## Работа с API

Базовый адрес:

```text
https://www.cheapshark.com/api/1.0
```

Используемые endpoint'ы:

| Endpoint | Назначение |
| --- | --- |
| `GET /deals` | Поиск, фильтрация, сортировка и аналитика предложений |
| `GET /stores` | Получение названий и состояния магазинов |

API-клиент расположен в `src/api/cheapshark.js`. Он собирает query string, не отправляет пустые параметры и преобразует логические параметры в значения, понятные CheapShark.

CheapShark не предоставляет жанровые теги. Поэтому поиск по тегам представлен быстрыми фильтрами на основе доступных полей API. При выборе скидки от 50% предложения автоматически сортируются по размеру скидки и фильтруются по заданному порогу.

## Аналитика

Страница аналитики запрашивает до 60 активных скидок с сортировкой по `DealRating` и показывает:

- количество обработанных предложений;
- среднюю цену;
- среднюю и максимальную скидку;
- лучшую сделку по рейтингу CheapShark;
- распределение предложений по диапазонам скидки;
- распределение предложений по магазинам;
- зависимость цены от рейтинга сделки.

Модуль аналитики загружается лениво и не увеличивает начальную загрузку страницы поиска.

## Темы и адаптивность

В приложении доступны две темы:

- тёмная: чёрный и графитовый фон с розово-фиолетовым неоновым градиентом;
- светлая: белый и жемчужно-розовый фон с тем же градиентным акцентом.

При первом запуске учитывается системная тема. После переключения выбор сохраняется в браузере.

Основные контрольные точки адаптивности:

- больше `1100px`: каталог в три колонки;
- до `1100px`: каталог в две колонки;
- до `800px`: фильтры открываются отдельной кнопкой;
- до `560px`: каталог и аналитика переходят в одну колонку.
